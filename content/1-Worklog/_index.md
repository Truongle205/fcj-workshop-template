# Worklog

This worklog summarizes my contributions during the development of the **Smart Home IoT System on AWS** as an **Embedded System Developer**.

The project was completed over **7 weeks**, covering requirement analysis, embedded firmware development, secure communication with AWS IoT Core, system integration, testing, and documentation.

Throughout the project, my primary responsibility was the development of the ESP32-S3 firmware and the integration of hardware components with AWS cloud services. The work included configuring the embedded development environment, implementing sensor drivers, establishing MQTT over TLS communication, generating telemetry data, controlling the relay remotely, validating the complete system, and preparing the final technical documentation.

The embedded platform and technologies used during the project include:

- ESP32-S3 Development Board
- PlatformIO
- Arduino Framework
- MQTT over TLS 1.2
- DHT11 Temperature and Humidity Sensor
- LDR Light Sensor
- Magnetic Door Sensor
- Relay Module
- JSON Telemetry
- Wi-Fi Communication
