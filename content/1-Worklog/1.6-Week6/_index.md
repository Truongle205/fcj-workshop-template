# Week 6 Worklog

## Week 6 Objectives

The objective of this week was to validate the embedded firmware under real operating conditions and verify reliable communication between the ESP32-S3 and AWS IoT Core.

## Tasks Completed

| Day | Task |
|---|---|
| Monday | Tested temperature, humidity, light, and door sensor readings under different conditions. |
| Tuesday | Verified periodic telemetry publishing from the ESP32-S3 to AWS IoT Core. |
| Wednesday | Tested remote relay control using MQTT command topics. |
| Thursday | Performed Wi-Fi and MQTT reconnection tests by simulating temporary network failures. |
| Friday | Verified firmware stability during long-term operation and monitored memory usage through the Serial Monitor. |

---

## Weekly Outcome

The embedded firmware operated reliably throughout the testing process. Sensor data were published correctly, remote relay control functioned as expected, and the firmware successfully recovered from temporary network interruptions.
