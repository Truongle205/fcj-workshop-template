# Smart Home IoT Workshop

This workshop provides a step-by-step guide to building a Smart Home IoT system using ESP32-S3 and AWS managed services.

The workshop covers device configuration, secure MQTT communication, telemetry collection, remote relay control, cloud data storage, event notifications, system testing, and resource cleanup.
